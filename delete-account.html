LUMI 계정 및 데이터 삭제 안내

LUMI - 감정일기 & CBT의 계정과 데이터를 삭제하거나, 계정을 유지한 채 일부 기록만 삭제할 수 있습니다. 앱을 설치하지 않아도 아래 이메일로 요청할 수 있습니다.

시행일: 2026-10-13

계정 삭제 계정 유지·일부 기록 삭제 앱 없이 이메일 요청 개인정보처리방침

1. 앱에서 계정과 서버 데이터 삭제

  1. 삭제할 LUMI 계정으로 로그인합니다. Google·카카오 로그인 모두 해당합니다.
  2. 설정 → 데이터 관리 → 계정 및 서버 데이터 삭제를 선택합니다.
  3. 삭제 범위를 확인하고 영구 삭제를 누릅니다.
  4. 서버 처리가 성공하면 로그아웃되며 해당 기기의 계정 관련 기록과 설정도 정리됩니다.

연결 오류나 삭제 실패 안내가 나오면 완료된 것으로 보지 말고 재시도하거나 이메일로 문의해 주세요. 이전 앱 버전에서 메뉴가 다르거나 사용할 수 없어도 아래 이메일 요청을 이용할 수 있습니다.

삭제는 되돌릴 수 없습니다. LUMI 계정이 삭제되며 Google·카카오 자체 계정은 삭제되지 않습니다. 필요한 기록은 먼저 내보내세요.

2. 계정을 유지하고 일부 데이터 삭제

  • 일기: 기록 목록에서 해당 일기를 열고 일기 삭제 → 확인창의 삭제를 선택합니다.
  • CBT: 해당 CBT 기록을 열고 삭제하기 → 확인창의 삭제를 선택합니다.
  • 로그인·동기화된 기록은 서버 삭제가 확인된 후 해당 기기에서 제거됩니다. 통신 오류가 표시되면 연결을 확인한 뒤 다시 시도해 주세요.
  • 그 외 데이터 또는 앱을 사용할 수 없는 경우: 아래 이메일로 삭제할 데이터 종류와 기록 날짜·제목·글 링크 등 식별 정보를 적어 요청해 주세요. 본문 전체를 보내지 않아도 됩니다.

개별 기록 삭제로 계정이나 다른 기록이 함께 삭제되지는 않습니다. 삭제된 개인 기록의 본문은 제거되지만, 다른 기기에서 복원되지 않도록 기록 ID와 삭제 시각은 계정 삭제까지 남을 수 있습니다.

계정 유지·일부 데이터 삭제 요청

3. 앱 없이 이메일로 삭제 요청

  1. 아래 버튼을 누르거나 위 주소로 이메일을 보냅니다. 메일 앱이 열리지 않으면 주소를 복사해 사용해 주세요.
  2. 계정과 관련 데이터를 모두 삭제할지, 계정을 유지하고 일부 데이터만 삭제할지 적어 주세요.
  3. 로그인 방식(Google·카카오), 사용 중인 닉네임, 로그인 이메일(있는 경우), 회신받을 이메일을 적어 주세요. 로그인 이메일이 없는 카카오 계정도 요청할 수 있습니다.
  4. 본인 확인에 추가 정보가 필요하면 회신으로 안내합니다. 요청한 범위를 확인한 뒤 처리 결과를 회신합니다.

계정 및 서버 데이터 삭제 요청

비밀번호, 인증번호, 주민등록번호나 감정 기록 본문 전체를 보내지 마세요. 이메일 요청은 본인 확인 완료 후 최대 7영업일 이내 처리를 목표로 하며, 확인이나 처리가 지연되면 이유와 예상 일정을 안내합니다.

4. 해당 기기의 데이터만 삭제

LUMI 앱 → 설정 → 데이터 관리 → 모든 데이터 삭제 → 삭제를 선택하면 해당 기기에 저장된 기록·초안·설정 등을 삭제합니다.

‘모든 데이터 삭제’는 해당 기기의 데이터 삭제입니다. 서버 계정·동기화 기록을 삭제하는 기능은 아닙니다. 서버 삭제는 1번 또는 2번 방법을 사용해 주세요. 다른 기기나 직접 내보낸 파일·스크린샷도 별도로 정리해야 합니다.

앱 저장공간과 캐시까지 비우려면 Android 설정 → 앱 → LUMI → 저장공간에서 데이터·캐시 삭제를 사용할 수 있습니다. 기기 제조사에 따라 메뉴 이름은 다를 수 있습니다. 앱 제거만으로 서버 데이터가 삭제되지는 않습니다.

6. 삭제 후 남을 수 있는 정보와 기간

  • Firebase 인증 데이터: 계정 삭제 후 앱 로그인은 종료됩니다. Firebase 정책에 따라 운영·백업 시스템에서 인증 데이터가 제거되기까지 최대 180일이 걸릴 수 있습니다.
  • Crashlytics 오류·진단: Firebase 정책에 따라 90일 보관 후 운영·백업 시스템에서 제거 절차가 시작됩니다.
  • Analytics 사용 분석: 서비스의 보관 설정과 Google Analytics 정책을 따릅니다. 일반 GA4의 사용자·이벤트 데이터 설정은 2개월 또는 14개월이며, 재이용 시 갱신되는 식별자와 집계 보고서는 별도 기준이 적용될 수 있습니다. 계정 삭제가 분석·진단 데이터의 즉시 전체 삭제를 의미하지는 않습니다.
  • 공개 게시판 삭제 표식: 삭제한 글이 다른 기기에서 다시 나타나지 않도록 글 ID·게시판 종류·삭제 시각을 동기화에 필요한 동안 유지합니다. 본문이나 계정 UID는 표식에 저장하지 않습니다. 개인 일기·CBT의 삭제 표식은 계정 삭제 때 제거됩니다.
  • AI 처리·기술 로그: MAI 요청 처리 환경의 접속·오류 로그는 Vercel·ngrok 등 제공업체의 정책과 설정을 따릅니다. AI 전송 원문 또는 로그의 보관·삭제 확인은 이메일로 요청해 주세요.

진단·분석 데이터에는 설치 식별자가 포함될 수 있으므로 모든 데이터가 완전히 익명이라고 보장하지 않습니다. 자세한 처리 방식은 개인정보처리방침의 보관 기간, Firebase 보관 정책, Analytics 보관 정책을 참고해 주세요.

7. 처리 시점과 문의

  • 기기 데이터: 해당 기기에서 삭제 작업 시 처리됩니다.
  • 앱의 개별 기록·계정 삭제: 서버 작업이 성공하면 앱에 결과가 반영됩니다. 데이터 양과 연결 상태에 따라 시간이 걸릴 수 있습니다.
  • 이메일: 본인 확인 완료 후 최대 7영업일 이내 처리를 목표로 하며 지연 시 안내합니다.
