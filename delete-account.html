LUMI 계정 및 데이터 삭제 안내

LUMI 사용자는 언제든지 계정 및 데이터의 삭제를 요청할 수 있습니다. 이 페이지에서는 데이터 삭제 방법, 삭제되는 데이터, 보관되는 데이터에 대해 안내합니다.

시행일: 2026-05-29

1. 기기 내 로컬 데이터 삭제

기기에 저장된 일기, CBT 기록, 감정 기록 및 앱 설정을 즉시 삭제할 수 있습니다.

  • LUMI 앱 → 설정 → 데이터 관리 → 모든 데이터 삭제

이 기능은 기기 내 로컬 데이터만 삭제합니다. Firebase 서버에 동기화된 데이터 및 계정 정보는 별도로 삭제 요청이 필요합니다.

2. 서버 데이터 및 계정 삭제 요청 (회원 탈퇴)

Firebase 서버에 저장된 동기화 데이터, 커뮤니티 게시글, 익명 글 및 Google 연동 로그인 계정을 완전히 삭제하려면 아래 방법 중 하나로 요청해 주세요.

방법 A. LUMI 앱 내 설정에서 간편 삭제

  • LUMI 앱 → 설정 → 계정 삭제 메뉴 → 안내 사항 확인 삭제 진행

방법 B. 이메일로 직접 요청

  • 아래 이메일로 가입한 Google 계정 이메일 주소와 사용 중인 닉네임을 적어 보내주세요.
  • 삭제 요청 이메일: kjd12359@gmail.com

3. 삭제되는 데이터

계정 및 데이터 삭제 요청이 처리되면 다음 데이터가 영구적으로 삭제됩니다.

데이터 유형 처리
계정 정보 (UID, 이메일, 표시 이름) 삭제
감정 기록 및 일기 삭제
CBT 기록 삭제
커뮤니티 게시글 및 댓글 삭제
앱 설정 정보 (알림, 잠금 등) 삭제
Google 로그인 연동 정보 및 관련 계정 데이터 삭제 (요청 시)

4. 보관될 수 있는 데이터

다음 데이터는 법령상 의무 또는 서비스 운영 목적에 따라 일정 기간 보관될 수 있습니다.

데이터 유형 보관 기간 사유
오류 및 진단 로그 (Crashlytics) 최대 90일 서비스 안정성 개선
앱 사용 분석 데이터 (Analytics) 정책에 따른 기간 Google Analytics 정책에 따른 기간 동안 보관

보관 기간이 경과한 데이터는 자동으로 삭제됩니다. 보관 중인 데이터는 식별 불가능한 형태로 처리되며, 마케팅 또는 광고 목적으로 사용되지 않습니다.

5. 삭제 처리 기간

  • 로컬 데이터 삭제: 앱 내에서 즉시 처리
  • 서버 데이터 및 계정 삭제: 이메일 접수 후 최대 7영업일 이내 처리

⚠️ 삭제된 데이터는 복구할 수 없습니다. 삭제 전 필요한 데이터를 반드시 백업해 주세요.

6. 로컬 데이터의 완전한 제거

기기에 캐시나 임시 파일 형태로 남아있을 수 있는 데이터까지 완전히 제거하려면, 앱 내에서 '모든 데이터 삭제'를 실행한 후 LUMI 앱을 기기에서 삭제(언인스톨)해 주세요.
